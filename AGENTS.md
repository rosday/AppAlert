# AppAlert agent entrypoint

For issue creation or maintenance in this Pretty Progress repository, follow the [app-owned checklist](https://github.com/rosday/pretty-progress-brain/blob/main/Workflows/Development.md#create-and-maintain-issues). Verify the owning backlog with the owner before creation; no dedicated implementation Project is established for this auxiliary repository by that workflow. Do not silently use the Brain board.

Keep technical instructions beside the source and follow applicable local documentation for the authorized task. Preserve unrelated work and existing fields. Project membership, assignment and Version do not authorize implementation or publication. Private company Brain access is not required.

When you work on a ticket and Rodrigo asks for a PR or a merge into main (or something similar), also update the ticket: follow the app-owned [PR and merge step](https://github.com/rosday/pretty-progress-brain/blob/main/Workflows/Development.md#pr-and-merge) (`Closes #n`, issue comment with the PR and verification, Status to review; on merge Done, Version and closing note, #7 dates, read-back).
